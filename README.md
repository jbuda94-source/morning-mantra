# Morning Mantra

A phone web app: a daily variation of my morning mantra, 3 positive news headlines, and one reminder for the day.

- `content.js` — the mantra variations and reminders (edit freely; rotates by date, Pacific time)
- `api/news.js` — Vercel function that pulls headlines from Good News Network, Positive News, Reasons to be Cheerful, and Optimist Daily
- Install on iPhone: open in Safari → Share → Add to Home Screen
