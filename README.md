# Morning Mantra

A phone web app: a daily variation of my morning mantra, 2 Long Beach + 1 Orange County headline, a second themed mantra, and one reminder for the day.

- `content.js` — the mantra variations and reminders (edit freely; rotates by date, Pacific time)
- `api/news.js` — Vercel function that pulls headlines from Long Beach Post, LB Business Journal, LB Watchdog, Voice of OC, OC Register, and Daily Pilot
- Install on iPhone: open in Safari → Share → Add to Home Screen
